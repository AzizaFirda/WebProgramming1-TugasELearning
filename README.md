# 🌐 Personal Website - Aziza Firdaus

Sebuah website personal sederhana yang dibuat menggunakan **HTML**, **CSS**, dan **JavaScript**.  
Website ini menampilkan informasi tentang biodata singkat saya.

---

## ✨ Fitur Utama
- 🎨 Desain modern dan minimalis  
- 📱 Responsif untuk berbagai ukuran layar   
- 🧍‍♂️ Tombol interaktif untuk menampilkan biodata  
- 💡 Dibuat sebagai latihan pengembangan web dasar

---

## 🧠 Teknologi yang Digunakan
| Teknologi | Deskripsi |
|------------|------------|
| **HTML5** | Menyusun struktur halaman |
| **CSS3** | Mengatur tampilan dan layout responsif |
| **JavaScript** | Menangani logika interaktif |
